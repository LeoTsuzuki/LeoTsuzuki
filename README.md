## 🚀 Projetos em Destaque

### 🤖 Buscador e Analisador de Vagas com IA

Protótipo desenvolvido para facilitar a busca de oportunidades profissionais utilizando integração com API e recursos de inteligência artificial.

**Funcionalidades propostas:**
- Busca de vagas por palavras-chave e áreas de interesse
- Integração com API de oportunidades de emprego
- Análise de requisitos das vagas com auxílio de IA
- Comparação entre descrições das vagas e informações do currículo
- Sugestões de adaptações sem adicionar competências inexistentes

**Conceitos:** Integração de APIs · IA Generativa · Análise de Informações · Desenvolvimento Assistido por IA

*Projeto experimental desenvolvido com apoio de ferramentas de inteligência artificial.*

### 📊 [InvestDash](https://github.com/LeoTsuzuki/investdash) — Dashboard de Investimentos

Aplicação web para gerenciamento e acompanhamento de investimentos e informações financeiras.

**Funcionalidades:**
- Acompanhamento de ações, FIIs, ETFs e criptomoedas
- Consulta de cotações por meio da API do Yahoo Finance
- Controle de receitas e despesas
- Gráficos interativos para visualização de dados
- Feed de notícias relacionadas aos ativos

**Stack:** Python · Flask · SQLite · Chart.js · yfinance

[🔗 Acessar repositório](https://github.com/LeoTsuzuki/investdash)

### 📦 [Distribuidora Brasão](https://github.com/LeoTsuzuki/DistribuidoraBrasao) — Sistema de Gestão

Sistema desktop desenvolvido a partir de uma necessidade real de gerenciamento de uma distribuidora de carvão.

**Funcionalidades:**
- Cadastro de fornecedores, clientes e produtos
- Controle de estoque e vendas
- Gerenciamento de despesas
- Geração de relatórios em PDF
- Organização do código utilizando arquitetura MVC

**Stack:** Java · Swing · PostgreSQL · JDBC · JasperReports

[🔗 Acessar repositório](https://github.com/LeoTsuzuki/DistribuidoraBrasao)
